# Profile catalog

Profiles narrow retrieval emphasis and action types. They do not grant authority,
tools, or factual knowledge. Every profile uses the same generated brain manifest,
Tier 1 governance hubs, local result schema, approval controller, and evidence rules.

| Profile | Primary work | Retrieval emphasis | Actions |
| --- | --- | --- | --- |
| `general-secretary` | General completed staff work | communication, judgment, duties | approved `file.write` only |
| `agent-chief-of-staff` | Agent-report synthesis and coordination | roles, escalation, judgment | none |
| `communications-secretary` | Correspondence and briefing drafts | communication, ethics, roles | approved `file.write` only |
| `operations-secretary` | Triage, sequencing, and paper flow | duties, escalation, judgment | approved `file.write` only |
| `research-secretary` | Source-bounded research and claim review | failure modes, gaps, judgment, questions | none |

The specialized profiles exist only where the repository already has distinct
domain hubs and testable routing needs. A profile is not a personality preset and
cannot relax provenance, dissent, approval, or no-data behavior.

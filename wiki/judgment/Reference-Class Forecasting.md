# Reference-Class Forecasting

## Operating Summary

Do not accept a first-pass duration estimate.

Maintain a reference class for each recurring task type.

Consult the observed class before making case-specific adjustments.

This outside view counters the planning fallacy named by Kahneman and Tversky.

HM Treasury institutionalized numeric optimism-bias uplifts in supplementary
Green Book guidance.

The digest directs the Secretary to quote from a reference-class table before
case-specific reasoning.

That implementation is digest-directed encoding.

## Source-Led Facts

The digest traces the planning fallacy to Kahneman and Tversky in 1979.

It assigns `evidence-based` confidence to reference-class forecasting.

HM Treasury's supplementary Green Book guidance addresses optimism bias
([GOV.UK official host](https://gov.uk)).

The digest dates institutionalization to 2003 and identifies the current cited
version as 2013.

The guidance mandates numeric uplifts.

The digest gives a non-standard civil-engineering capital-expenditure example
of plus 66 percent.

The digest gives an equipment and development capital-expenditure example of
plus 200 percent.

These are examples for the project categories in the cited guidance.

They are not default uplifts for Secretary tasks.

The digest's encoding says never to accept a first-pass duration estimate.

It says to hold a reference-class table per recurring task type.

It says to quote from that table before case-specific reasoning.

## Operating Procedure

The following procedure is synthesis directed by the digest.

1. Name the recurring task type.
2. Retrieve completed instances in the same reference class.
3. Separate the recorded estimate from the actual duration.
4. Prefer actual outcomes for the class baseline.
5. State how many completed instances support the class.
6. Quote the class result before discussing the current case.
7. Record the current item's first-pass estimate without adopting it.
8. Compare that estimate with the class result.
9. Identify case-specific differences.
10. Adjust only after the outside view is visible.
11. Preserve the baseline and the adjustment separately.
12. After completion, add the actual result to the class.
13. Recalculate the class by a deterministic process.
14. Use [[ESI Resource Counting]] to identify resource complexity separately.

When no class exists, say `no data` for the reference class.

Do not replace the missing class with model memory.

Record the missing class as an open evidence need.

If an institutional uplift applies to a governed project category, cite the
specific guidance rather than transferring an example by analogy.

## Boundaries

The digest does not supply a complete reference-class table.

It does not state how many observations a Secretary task class requires.

It does not specify a statistic for the class baseline.

Do not invent a mean, median, percentile, or confidence interval.

The plus 66 percent example is category-specific.

The plus 200 percent example is category-specific.

Neither example is a generic Secretary correction.

Reference-class forecasting estimates outcomes.

It does not grant authority under [[Seven Delegation Levels]].

It does not change reversibility under [[Reversibility as the Master Gate]].

It does not establish importance under [[Urgency and Importance]].

Use [[Satisficing]] to bound option search, while keeping the outside view in the
record.

The digest does not provide a primary URL for the 1979 paper, so this note does
not invent one.

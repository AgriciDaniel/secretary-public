# Meeting Trim Attribution Correction

## Operating Summary

The 25 and 50 minute convention is documented as a Microsoft default, not as a Google rule (https://www.microsoft.com).
The Google Help index has no speedy-meetings wording. This verified absence
confirms the Microsoft-not-Google correction.

## Source-Led Facts

The Microsoft default reduces short events by five minutes (https://www.microsoft.com).
It reduces long events by ten minutes (https://www.microsoft.com).
The digest names the settings `DefaultMinutesToReduceShortEventsBy` and `DefaultMinutesToReduceLongEventsBy`.
The Google Help index contains no speedy-meetings text, a positive finding that
the 25 and 50 minute attribution is not supported there.

## Operating Procedure

Correct the attribution when it appears.
Do not turn either vendor default into a universal scheduling doctrine.

## Boundaries

The digest does not establish that shortened meetings improve outcomes.
This note corrects provenance only.

## Sources

- Microsoft documented defaults (https://www.microsoft.com).
- Google Help index checked for speedy-meetings text, verified absence.

# No-Surprises Not in FRC Code

## Operating Summary

The FRC UK Corporate Governance Code does not supply a no-surprises doctrine.
The formerly cited Crown Law doctrine is cited-but-unlinked, not verified here.
The Public Service Commission page is a verified analogue for free and frank
advice, not proof of the unavailable Crown Law claim.

## Source-Led Facts

The FRC checked absence supports correction of an FRC attribution. No reachable
primary record supports the detailed Crown Law receipt-conditions claim.

## Operating Procedure

Correct the FRC attribution. Cite [[communication/No-Surprises Protocol]] only as
contested local synthesis until a claim-level primary source is captured.

## Boundaries

This note establishes an attribution correction. It does not claim that the
phrase is absent from every UK organization.
